# Финансовая модель автошколы «ДВИЖ»

Интерактивный браузерный калькулятор экономики одного набора автошколы. Приложение находится в `index.html`, не требует сервера и публикуется через GitHub Pages после слияния изменений в основную ветку.

## Запуск
Откройте https://motostrelok1.github.io/fin.calc-dvizh/ или локально `index.html` в современном браузере. Данные автоматически сохраняются в localStorage под ключом `autoshkola_finmodel_v1`. **Экспорт JSON** сохраняет все настройки, **Импорт JSON** восстанавливает их, а **Сбросить настройки** возвращает исходную модель.

## Интерфейс
- Верхняя панель: выручка, общие расходы, прибыль, точка безубыточности.
- Расходы: общий выключатель постоянных расходов, категории, сотрудники, дополнительные пользовательские статьи и их ползунки.
- Маркетинг: проценты налога и маркетинга от выручки.
- Инструкторы: текущий штат, ёмкость по занятиям, загрузка и предупреждения.
- **Конструктор тарифов**: «Завлекающий», «Базовый», «Повышающий».
- Показатели: параметры сценария и сводная экономика.
- Юнит-экономика: средние показатели на курсанта.
Карточки перемещаются за специальную ручку, меняют размеры за угол и могут переключаться в компактный режим. При скрытых настройках карточка сокращается до высоты содержимого; прокрутки внутри карточек нет.

## Тарифы
Каждая вкладка тарифов хранит **собственные** значения: `students`, `price`, `theoryOnline`, `theoryClass`, `theoryIndividual`, три флага `theory*Enabled`, `hours`, `duration`, `lessonPrice`, `sim`.

Порядок полей: **стоимость курса**, **количество курсантов выбранного тарифа**, подблок **Теория**, подблок **Практика**.

### Теория
Три независимых чекбокса: **Теория онлайн**, **Теория в классе**, **Теория индивидуально**. У каждого ползунок **0–15 000 ₽**, шаг **500 ₽**. Выключение исключает значение **только из суммы включённой теории**; сохранённая величина остаётся доступной при повторном включении. Это именно независимые переключатели, а не взаимоисключающие radio.

`theoryTotal(t) = Σ(t[modeEnabled] ? t[mode] : 0)`

**Цена курса не формируется автоматически из суммы теории и практики.** Это установленная пользователем *продажная стоимость* тарифа, от которой считается выручка. Значения теоретических компонентов используются для анализа состава тарифа и отображения среднего значения теории; они не прибавляются к выручке и не включаются автоматически в расходы. Для будущего отражения себестоимости теории требуется отдельное бизнес-правило.

### Практика
- Часы вождения: **0–58 часов**, шаг 1 час.
- Продолжительность занятия: 2 или 3 часа.
- Стоимость одного занятия: **500–2 500 ₽**, шаг 50 ₽.
- Тренажёр: при включении исключаются 2 часа из объёма вождения.
- `lessons(t) = floor(max(0, t.hours - (t.sim ? 2 : 0)) / t.duration)`
- `drivingCost(t) = lessons(t) × t.lessonPrice`.

### Распределение курсантов
По всем трём тарифам суммарно не более **100 курсантов**. Слайдер в выбранной вкладке ограничен свободными местами, с учётом двух остальных тарифов. В исходной модели 15 курсантов относятся к базовому тарифу.

### Компактная карточка — средние по всем тарифам
Средние **взвешены по количеству курсантов**, а не вычисляются простым средним по трём тарифам. Тариф с нулём курсантов не влияет на средние. Для нулевого общего набора значение среднего равно нулю.

- Средняя цена курса = `Σ(students_i × price_i) / Σstudents_i`
- Всего курсантов = `Σstudents_i`
- Средняя стоимость включённой теории = `Σ(students_i × theoryTotal_i) / Σstudents_i`
- Средние часы практики = `Σ(students_i × hours_i) / Σstudents_i`
- Среднее число занятий = `Σ(students_i × lessons_i) / Σstudents_i`
- Средняя стоимость практики = `Σ(students_i × drivingCost_i) / Σstudents_i`

## Финансовые формулы
- Выручка = `Σ(students_i × price_i)`.
- Занятия = `Σ(students_i × lessons_i)`.
- Расходы на вождение = `Σ(students_i × drivingCost_i)`.
- Налог = `revenue × taxPercent / 100`.
- Маркетинг = `revenue × marketingPercent / 100`.
- Постоянные расходы = сумма включённых категорий и пользовательских статей, либо **0** при выключенном общем переключателе расходов.
- Итоговые расходы = вождение + налог + маркетинг + постоянные.
- Прибыль = выручка − итоговые расходы.
- Средний вклад с курсанта = (выручка − налог − маркетинг − вождение) / все курсанты.
- Точка безубыточности = `ceil(fixed / avgContribution)` (если вклад положителен; иначе недостижима). **Допущение:** состав тарифов при росте набора остаётся неизменным.

Расчёт смешивает показатели по полному курсу одного набора и **месячные** постоянные расходы. Он не моделирует календарь платежей, налоговый учёт или полный помесячный P&L; применять как сценарную модель, не как бухгалтерскую отчётность.

## Инструкторы
Спрос по занятиям = сумма занятий всех тарифов. Доступная мощность = количество инструкторов × лимит занятий на инструктора. Если спрос превышает мощность, штат автоматически увеличивается (макс. 20). При загрузке меньше **70%** штат уменьшается до минимального необходимого; в диапазоне **70–100%** остаётся прежним. Штат всегда не менее 1.

## Хранение и миграция
Ключ localStorage сохраняется прежним: `autoshkola_finmodel_v1`. Импорт старых файлов без `tariffs` переносит параметры старой единственной программы в базовый тариф. Старые тарифы без флагов `theory*Enabled` получают флаг по положительной сумме компонента: `true` при значении больше нуля, иначе `false`. Поля с выключенным компонентом сохраняют сумму. Флаги и значения сериализуются в JSON вместе с расположением, размерами и видимостью карточек.

## Ручная проверка после PR
1. Открыть каждую вкладку, изменить стоимость, количество курсантов, три вида теории и параметры практики; вернуться — значения должны сохраниться отдельно.
2. Выключить теорию онлайн с ненулевой суммой: строка визуально приглушается, её доля исключается из «Включённая теория», но цена курса и выручка **не меняются**. Включить обратно — сумма восстанавливается.
3. Распределить курсантов 2/3/5 по тарифам с разными ценами; проверить средневзвешенную цену и итог **10 курсантов** в компактном виде.
4. Проверить средние часы, занятия и стоимость практики для тарифов с разными длительностями.
5. Проверить пересчёт загрузки инструкторов по **всем** тарифам и пороги 70/100%.
6. Уменьшить высоту компактной карточки: пустоты и внутренней прокрутки быть не должно.
7. Перезагрузить страницу; проверить сохранение вкладок, ползунков, чекбоксов, размеров.
8. Экспортировать и импортировать JSON, в том числе старую модель без тарифов.
9. Проверить мобильную узкую ширину и отсутствие налезания переключателей на заголовки.

## Ограничения
Нет сервера, авторизации, синхронизации между устройствами, отдельной себестоимости преподавателей теории, распределения постоянных расходов по месяцам и учёта пересдач. Верхний диапазон стоимости курса — 80 000 ₽, всего учащихся — 100. Структура сохранения допускает последующее расширение модели.
